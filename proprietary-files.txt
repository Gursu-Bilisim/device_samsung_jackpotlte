# Audio HAL
# Stock A530FXXULCUK6 HAL, which the stock build loads from the system
# partition as audio.primary.universal7885.so. It matches this phone's ABOX
# PCM layout; the A750F HAL used before (lineage-18.1 list) opened pcmC0D9p
# for the voice call TX, which is a capture device here, and the modem
# crashed when a call connected. The stock libaudioroute reads the CUK6
# mixer_paths.xml as is (the common one rejects path names with
# master/slave). Other Samsung audio libraries come from the common vendor;
# the HAL uses no symbol from the stock ones that those lack. It is built
# against the Android 9 audio headers, so it is installed under another name
# and loaded by the audio.primary.exynos7885 wrapper (audio/), which converts
# the structures that changed since.
lib/hw/audio.primary.universal7885.so:vendor/lib/hw/audio.stock.exynos7885.so;DISABLE_DEPS
