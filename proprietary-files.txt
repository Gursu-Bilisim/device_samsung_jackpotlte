# Blobs for Samsung Galaxy A8 2018 (jackpotlte), all from the stock
# A530FXXULCUK6 firmware (BTU), the same build as the bootloader on the phone.
# Started from the LineageOS 18.1 jackpotlte list (exynos7885-dev,
# d6885b5); hash pins dropped because that list took audio and camera
# from other firmwares (A750FNXXU5CVG2, SC02LOMS1CVK2).
# Libraries that vendor/samsung/exynos7885-common already installs as
# modules (a30 Android 11 audio and sensor helpers) are left out to avoid
# duplicate install rules.
